# Omega Effective-Action Discovery Results R1

Status: **FINITE LATTICE FORMAL/COMPUTATIONAL RESULTS - NOT CONTINUUM OR EMPIRICAL QFT VALIDATION**

## Goal

Continue R12 by constructing the exact blocked probability measure and exact finite effective action, then test whether a simple symmetry-compatible phi4-like ansatz can reproduce it.

The microscopic witness is the R12 periodic N=4 scalar lattice with values in {-1,0,1}, kappa=m2=lambda=1, and two-site block averaging.

## Exact push-forward measure

For a coarse state y=B(phi), define the unnormalized pushed weight

W(y) = sum_{phi: B(phi)=y} exp(-S(phi)).

Then

Z = sum_y W(y)

and

P(y)=W(y)/Z.

The blocked support contains 25 states.

## T28 - exact normalization and Z2 inheritance

The push-forward preserves total weight:

sum_y W(y) = sum_phi exp(-S(phi)).

Because S(-phi)=S(phi) and B(-phi)=-B(phi),

W(-y)=W(y)

and therefore

P(-y)=P(y).

So the exact blocked measure inherits the microscopic global Z2 symmetry.

## T29 - exact finite effective action

Define on the blocked support

S_eff(y) = -log W(y).

Then

exp(-S_eff(y)) = W(y),

so the Boltzmann distribution generated by S_eff reproduces the pushed measure exactly, with the same partition function.

As usual, adding an overall constant to S_eff changes only the partition-function normalization and not the normalized probabilities.

## Phi4-like effective ansatz

On a two-site coarse field y=(a,b), define

M2 = (a^2+b^2)/2,
M4 = (a^4+b^4)/2,
C1 = a b.

The base effective-action family is

S_base(y) = c0 + c2 M2 + cC C1 + c4 M4.

The coefficients are selected by uniform-support least squares against the exact S_eff on all 25 blocked states.

## T30 - nested operator spaces cannot increase least-squares residual

If model space V is contained in model space V', then

min_{v in V'} ||S_eff-v||_2^2 <= min_{v in V} ||S_eff-v||_2^2.

This follows because every candidate in V remains available in V'.

Hence a newly added operator may leave the residual unchanged, but cannot worsen the optimal least-squares residual when the fit is recomputed exactly.

## N11 - simple phi4-like blocked action is not exact for the finite witness

For the 25-state R13 support, the optimized base family has

RSS = 0.018409402678442...
RMS residual = 0.027136250793684...
max absolute residual = 0.040477037232416...

Thus the base phi4-like family does not exactly reproduce the finite pushed effective action within numerical tolerance.

This is not a failure of microscopic phi4 theory. It is an explicit demonstration that coarse-graining can generate effective structure outside a restricted retained operator family.

## Residual operator court

The following symmetry-compatible extensions are tested one at a time:

- M2^2,
- Delta4 = (a-b)^4,
- M2*C1,
- M6 = (a^6+b^6)/2.

Two independent score axes are used:

1. action-space gain:
   base_RSS - candidate_RSS;
2. distribution-space gain:
   KL(P_exact || P_base) - KL(P_exact || P_candidate).

### Action-space result

Adding M2^2 gives the largest tested RSS improvement:

base RSS = 0.018409402678442...
extended RSS = 0.016695723808311...
gain = 0.001713678870131...

### Distribution-space result

The base normalized model has

KL(P_exact || P_base) = 0.000298890822759...

Adding Delta4 gives

KL(P_exact || P_Delta4) = 0.000296609326760...

with positive KL gain approximately

2.281495999e-6.

By contrast, M2^2 improves action-space RSS but slightly worsens KL in this witness.

## T31 - objective dependence of operator ranking

The finite court therefore has no metric-independent winner among the tested single-operator extensions:

- M2^2 is preferred by uniform-support action RSS;
- Delta4 is preferred by normalized distribution KL.

This is a concrete Anti-Ego / Pareto result: candidate ranking must carry its scoring functional and cannot be collapsed into an unqualified "best operator".

## Scientific boundary

R13 verifies a finite exact push-forward, exact support-level effective action, and numerical operator-projection court for the R12 toy lattice.

- a continuum RG flow,

- renormalized physical couplings,
- a new particle or interaction,
- empirical agreement.
